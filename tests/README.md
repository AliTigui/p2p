# Cross-crate test suites

Rust unit and integration tests live beside the code in each crate. This directory records the intended layout for future cross-crate suites:

- `unit/` — pure logic shared across crates (planned).
- `integration/` — storage, crypto, and app-facade integration tests (currently beside their crates).
- `networking/` — two-process and two-machine libp2p tests (two-instance tests currently in `crates/network/tests/` and `crates/chat/tests/`).
- `cryptography/` — known-answer and interop tests (planned).
- `security/` — fuzz targets and adversarial input tests (planned).
